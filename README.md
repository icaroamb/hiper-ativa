# Hiper Ativa — proposta de landing page

Proposta de nova landing page para a Hiper Ativa · Medicina e Estética Avançada (Anápolis-GO).
**Não é o site oficial da clínica.**

- Layout gerado no Google Stitch a partir de briefing com conteúdo real do site e do perfil no Google.
- Página estática: `index.html` + Tailwind via CDN + fotos reais em `assets/`.
- `DESIGN.md`: sistema visual (cores, tipografia, componentes).
- Marcada com `noindex` para não aparecer nos buscadores.

Antes de virar site oficial, validar com a clínica: número do endereço, respostas do FAQ e uso de fotos e depoimentos.
